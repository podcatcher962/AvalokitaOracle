## English

**Avalokita Oracle** is an online lot-drawing tool based on traditional Chinese GuanYin (Avalokitesvara) lot culture. Calm your mind with the Heart Sutra, draw a lot, read the verse, meaning and allusion, then receive a peace-of-mind message and action plan. All 100 lots included, with three ways to use: type, choose, or random—no typing needed.

### ✨ Features

| Module | Description |
|---|---|
| 📜 **100 lots** | Verse, meaning, allusion, fortune complete |
| 🧘 **Ritual feel** | Heart Sutra recitation + breathing animation |
| 📿 **Mantra & homage** | Avalokitesvara homage + Om Mani Padme Hum + Sanskrit original |
| 💗 **Peace of mind** | Comfort tailored to each fortune level |
| ✅ **Action plan** | Three suggestions by fortune |
| 💭 **20 preset wishes** | Career, Love, Wealth, Health, etc. |
| 🎲 **Quick random draw** | Random wish + direct draw, zero input |
| 🖼️ **Card download** | PNG card with fortune coloring |
| 🌐 **Bilingual** | Full Chinese/English toggle |
| 🌙 **Themes** | Parchment + dark, remembers preference |

### ⚠️ Disclaimer

Built upon traditional Chinese GuanYin lot culture, all content is for **cultural study and spiritual comfort**. It is not scientific prediction, religious ruling, therapy, or any professional service.

Verses, meanings, and allusions are folk tradition; versions may vary slightly. This tool offers no medical, legal, financial, or therapeutic advice; action plans are general references only. Seek professionals if in serious distress.

Never use lots as the sole basis for major decisions (marriage, investment, career, medical). Drawing lots seeks peace and encouragement—your path is still yours to walk.

Pure front-end single-file app. No server, no tracking. Data stays in your browser only. Open-sourced for personal study and entertainment; commercial misuse is prohibited.
